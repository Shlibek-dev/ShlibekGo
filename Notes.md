## Never Forget:
### Android development layers several subjects together:
- programming (Kotlin)
- object-oriented programming
- debugging
- Gradle
- Android Studio
- Jetpack Compose or XML layouts
- Android lifecycle
- APIs
- architecture

 *Many beginners assume Android is one skill. It isn't—it's an ecosystem.*

- Android development is enormous.
- There are many technologies, libraries, tools, and architectural patterns.
- The key is recognizing that you don't need to master all of them to build useful apps.

- how Kotlin, Android, Jetpack Compose, Gradle, APIs, Room, MVVM, Coroutines, etc. fit together?

## For your Android learning path:
 don't try to master all of these frameworks independently. Learn them in the order they participate in the application's architecture:
1. Kotlin
2. Compose
3. ViewModel
4. Navigation
5. Coroutines
6. Flow / StateFlow
7. Room
8. Retrofit
9. Repository pattern
10. Hilt
11. WorkManager, Paging, and other specialized Jetpack libraries.

## Note:
the minimum to build an Android app is:
- A programming language (Kotlin or Java)
- The Android SDK (the APIs provided by Android itself)
- A build system (Gradle, which Android Studio sets up for you).

Everything else—Compose, ViewModel, Room, Retrofit, Hilt, etc.—is built on top of those foundations.

## Gradle:
Gradle's main jobs are to:
- Build your app.
- Download and manage dependencies (libraries).
- Compile your Kotlin code.
- Package everything into an installable app (APK or App Bundle).

## What's API?
An API (Application Programming Interface) is a defined set of functions, classes, methods, or endpoints that one piece of software exposes so that another piece of software can use its capabilities.
